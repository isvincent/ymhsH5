# 梅岡時光機｜楊梅高中校史動態影片（1968 → 2026）

開啟 `index.html` 就能播放：單一 HTML 檔，畫面全部是內嵌 SVG，長度約 300 秒，畫面 1920×1080（16:9 橫式），以 30 fps 為目標。

- **畫面**：青春校園拼貼風（拍立得、紙膠帶、便利貼）。用逐年翻頁的「空中視角」呈現校園與楊梅市街的變化：1990 年前用黑白航照質感，2000 年後轉成彩色。
- **配樂**：開啟網頁時用程式即時原創合成，F 大調，2000 年那一章轉到 G 大調，搭配時鐘滴答聲營造時間推進感。
- **音效**：翻頁聲、轉場聲、里程碑鐘聲、便利貼彈出聲，全部用程式合成。
- **旁白**：使用瀏覽器的 Web Speech API 和預設語音（zh-TW），語速 1.15；畫面上同步顯示字幕。
- **互動**：點畫面底部的年份標籤可以跳到那一年；空白鍵播放／暫停，← → 快退／快轉 5 秒；可分別開關旁白、音樂、字幕；有「資料來源」面板。
- 在網址加上 `?t=秒數`，可以查看任一時間點的靜止畫面（例如 `index.html?t=133`）。

## 重要說明
- 片中的空中視角是**依年代示意重繪**，不是實際的衛星或航照影像。真實的歷年影像可以到 Google Earth 歷史影像、中研院「臺灣百年歷史地圖」、林業及自然保育署航測及遙測分署（舊航照）、國土測繪圖資服務雲比對。
- 只採用 1968 年省立楊梅高級中學成立以後的史料，不含楊梅國中的資料。
- 待查證：悅知樓的實際啟用日期（市府原本預計 2021 年 6 月前完工）；校長名單依學校簡介所列，片中沒有標註任期。
